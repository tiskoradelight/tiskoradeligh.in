# Tiskora Delight — 0% EMI Product Showcase

Free static website for showcasing products to local customers.

## Files
- `index.html` — complete website
- `products.js` — products, prices, image URLs and WhatsApp number

## Before publishing
1. Open `products.js`.
2. Replace `919XXXXXXXXX` with your WhatsApp number.
3. Replace the sample products with your real products.
4. Replace image URLs with your product image URLs.
5. Commit/upload the files to your GitHub repository.
6. Enable GitHub Pages from repository Settings → Pages → Deploy from branch → main → /(root).

## Important
The EMI calculator is only a mathematical planning estimate. Display "0% EMI" only when your actual customer arrangement is genuinely zero-interest/zero-cost on the terms you advertise, and clearly disclose any applicable down payment, processing fee, taxes or other charges.
